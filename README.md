# 念日

一个轻量的 Android 重要日期提醒应用。当前版本为 `1.0.9`，支持 Android 8.0（API 26）及以上。

## 已实现

- 添加、编辑和删除生日、纪念日及其他重要日期
- 默认提供全部、生日、纪念日和其它标签；支持新建、改名和删除日期标签
- 从“全部”新建时默认选中第一个日期标签；从具体标签新建时自动沿用当前标签
- 标签使用稳定 ID，改名不会丢失日期关联，删除标签也不会删除日期
- 年份可不填；每年重复按月日计算，单次提醒自动锁定下一次出现的日期
- 公历与中国农历日期，离线换算范围为 1900—2100 年
- 在公历与农历之间切换时保留同一个实际日期；新建页默认的“明天”会正确换算为对应农历
- 日期与提醒时间选择器使用念日的暖白圆角卡片和珊瑚色操作按钮
- 提醒日期改为可多选的圆角选项，选中时使用珊瑚色和勾选标记
- 日期类型在编辑页内使用可横向滑动的标签选择；本机日历导入和准点权限提示均使用念日风格
- 闰月改为开关交互，日期与时间选择弹窗针对大屏手机收窄
- 每年自动重复；过期后自动计算下一年度并重新排序
- 点击首页标题“念日”打开设置；设置按提醒、日期与标签、农历与数据、关于分为四个二级页面
- 首页右上角保留“批量”和“收纳”，从右侧打开日期收纳，集中查看已结束日期和回收站
- 删除操作使用与应用一致的圆角确认卡片；删除的日期保留在本机回收站，并显示具体删除时间
- 回收站中的日期可恢复并重新登记提醒；“已结束”可一键移入回收站，回收站可一键永久清空，两者均会二次确认
- 日期详情页的删除、取消和保存使用与应用一致的圆角按钮
- 新增与编辑日期都使用独立全屏页面，不再使用弹窗表单
- 今天且已开启“当天提醒”的日期，在提醒时间前显示剩余小时和分钟，每分钟自动刷新
- 当天、提前 1 天、提前 7 天的本地通知，每个日期可在 `00:00—23:00` 之间自定义整点提醒
- 新增日期默认开启提醒；可单独关闭某个日期的提醒，保留日期与原有提醒选项
- Android 13 及以上使用日历提醒类应用的精确闹钟权限；Android 12 需要用户在系统中开启“闹钟和提醒”
- 提醒设置提供“立即测试通知”和“1 分钟后测试提醒”，可分别验证通知展示与系统定时唤醒
- 测试结果会记录系统是否唤醒应用、应用是否提交通知，并提供后台与自启动设置入口
- 到点时应用正在前台，会在 2 分钟的准点窗口内补齐当次通知；超过窗口后重新打开应用只显示一次 Toast，不补发系统通知
- 单次日期在当天全天保留于首页，次日零点后进入“已结束”；每年重复日期不会进入收纳
- 手机重启、系统时间或时区变化后重新登记提醒
- 定时闹钟到点后使用短时前台服务送达通知，服务随即停止，不需要应用常驻
- 重要日期默认同时开启声音和振动；声音跟随系统默认闹钟铃声与闹钟音量，声音和振动可分别关闭
- 每个日期默认跟随全局声音与振动设置；也可单独设为声音+振动、仅声音、仅振动或静默
- 到点时只显示系统顶部通知，并按配置使用系统默认闹钟声音和振动；不再强制弹出或覆盖锁屏页面
- 系统静音、勿扰和通知频道优先级仍由用户控制，应用不强行绕过系统策略
- 后台设置使用念日风格的分步引导卡片，自动识别华为、荣耀、小米/Redmi、vivo/iQOO、OPPO/realme/一加和三星
- 按品牌提示自启动、后台活动和电池策略，提供启动管理、应用信息和电池设置入口
- 从本机系统日历选择事件导入（只在用户操作时申请读取权限）
- 单条日期可通过系统日历界面添加，无需应用直接写入
- 在首页批量选择多个日期，选择目标日历后一次性写入，自动跳过同名同时间事件
- 批量日期和目标日历均使用与首页一致的卡片式选择界面
- 可选联网检查国家标准全文公开系统和紫金山天文台资料是否可访问
- 日期数据只保存在应用本地，不需要账号，不依赖服务器

首次安装会加入四条演示日期，便于查看滚动排序与已结束区域；均可编辑或删除。

## 数据来源与边界

- 农历编排规则参考现行 `GB/T 33661-2017《农历的编算和颁行》`。
- 离线换算使用 MIT 许可的 `lunar-java 1.7.7`，许可文本见 `third_party/lunar-java-LICENSE.txt`。
- 首版的“联网检查”只验证权威来源连接，不会下载或覆盖本地农历数据。正式的签名数据更新包尚未接入。

## 权限

- `POST_NOTIFICATIONS`：Android 13 及以上显示提醒。
- `SCHEDULE_EXACT_ALARM`：Android 12 上由用户开启“闹钟和提醒”特殊权限。
- `USE_EXACT_ALARM`：Android 13 及以上用于日历类核心准点提醒。
- `VIBRATE`：允许重要日期通知按通知频道设置震动。
- `FOREGROUND_SERVICE`：仅在提醒到点时启动短时送达服务，提交通知后立即停止。
- `RECEIVE_BOOT_COMPLETED`：开机后恢复提醒。
- `READ_CALENDAR`：用于用户主动从本机日历导入，或在批量添加时选择目标日历及去重。
- `WRITE_CALENDAR`：仅用于用户主动执行批量添加到本机日历。
- `INTERNET`：仅用于用户开启或手动执行权威来源检查。

## 构建

需要 JDK 17 和 Android SDK 36：

```bash
export LC_ALL=zh_CN.UTF-8
export JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-17.jdk/Contents/Home
./gradlew :app:assembleDebug
```

测试与静态检查：

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug
```

调试 APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。
